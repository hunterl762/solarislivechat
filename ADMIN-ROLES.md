# Staff roles

| Capability | Admin | Agent |
|---|---:|---:|
| Sign in | Yes | Yes |
| View conversations | Yes | Yes |
| Reply to customers | Yes | Yes |
| Close conversations | Yes | Yes |
| Receive live notifications | Yes | Yes |
| View staff accounts | Yes | Yes |
| Create staff accounts | Yes | No |

Account activation/deactivation UI can be added as a later extension; the database already contains `is_active` and login enforces it.
