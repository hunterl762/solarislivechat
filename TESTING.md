# Test checklist

1. Start MySQL and the Node service.
2. Sign into `/chat/admin` as an administrator.
3. Click Notifications and grant browser permission.
4. Open the website widget in another browser/incognito session.
5. Send a visitor message and verify the admin unread badge, tone and desktop notification.
6. Reply from the admin console and verify the visitor widget badge, tone and title counter.
7. Minimize the visitor widget and repeat the reply test.
8. Create an agent from the Agents page and verify that account can sign in.
9. Verify an agent account cannot create another staff account.
10. Close the conversation and verify the visitor receives the closed state.
