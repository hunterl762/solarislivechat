# Visitor widget

`chat-widget.js` creates the floating Solaris Live Support button and conversation window. It retains the conversation ID in localStorage, shows agent availability, receives real-time replies, displays unread counts while minimized, updates the page title, and can show desktop notifications when browser permission has been granted.

The current build is designed for same-origin deployment. See `ADMIN-PANEL.md` before deploying the widget from a separate chat hostname.
