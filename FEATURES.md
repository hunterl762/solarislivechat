# Features

## Administration
Dashboard metrics, conversation search, unread counters, agent presence, agent account management, authenticated sessions, conversation closing and responsive Solaris UI.

## Notifications
Agent and visitor notification sounds, unread badges, tab-title counters, desktop notifications (with browser permission), and live support availability status.

## Roles
`admin` can create administrator or agent accounts. `agent` can sign in, view conversations, reply, and close chats but cannot create staff accounts.
